# EX-02-Cross-Platform-Prompting-Evaluating-Diverse-Techniques-in-AI-Powered-Text-Summarization

## Aim:
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: text summarization.

## Scenario:
You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience

# AI Tools Used:
* ChatGPT
* Gemini

## Algorithm
Step 1: Select a specific application, such as AI-based student performance prediction.

Step 2: Choose AI platforms such as ChatGPT and Gemini.

Step 3: Prepare five different prompt structures:
- Basic Prompt
- Role Prompt
- Context Prompt
- Constraint Prompt
- Output Format Prompt
Step 4: Enter the same prompts into both AI platforms.

Step 5: Generate responses for each prompting technique.

Step 6: Collect and save the generated outputs from both platforms.

Step 7: Evaluate the responses based on accuracy, coherence, simplicity, speed, and user experience.

Step 8: Compare the responses generated by ChatGPT and Gemini.

Step 9: Identify the most effective prompting technique and AI platform.

Step 10: Document the observations, comparison, and final results.

# EXPERIMENT:
## Designing Different Prompt Structures for AI-Based Student Performance Prediction
## Selected Application:
## AI-Based Student Performance Prediction
### 1. Basic Prompt:
Explain how Artificial Intelligence can be used to predict student academic performance based on attendance, assignment scores, study hours, and previous examination marks.

### 2. Role Prompt:
Act as an AI and Machine Learning professor and explain how a student performance prediction system works using attendance, assignment scores, study hours, and previous examination marks with simple examples.

### 3. Context Prompt:
A college wants to develop an AI-based system to identify students who may need academic support. Explain how Machine Learning analyzes attendance, assignment scores, study hours, and previous examination marks to predict student performance.

### 4. Constraint Prompt:
Explain how an AI-based student performance prediction system works in 100 words using simple English. Include attendance, assignment scores, study hours, previous examination marks, and two benefits of the system.

### 5. Output Format Prompt:
Explain an AI-based student performance prediction system, including its introduction, input factors, working process, and benefits. Present the working process in numbered steps and the benefits in bullet points.

## Most Effective Prompt Type
After evaluating all five prompting techniques using ChatGPT and Gemini, the Context Prompt was identified as the most effective overall technique.

Reasons for Selecting Context Prompt:
- Provides a clear real-world application.
- Helps the AI understand the purpose of the task.
- Produces relevant and meaningful explanations.
- Connects theoretical concepts with practical applications.
- Explains how student data can be used to identify students who need academic support.
Best Platform for Context Prompt: ChatGPT

ChatGPT performed slightly better because:
- It presented the working process in a clear manner.
- It organized the information into meaningful sections.
- It provided simple examples and understandable explanations.
- It included relevant benefits of the prediction system.
Gemini also generated a relevant response and explained the early warning system effectively. However, ChatGPT provided a more organized explanation for undergraduate students.
